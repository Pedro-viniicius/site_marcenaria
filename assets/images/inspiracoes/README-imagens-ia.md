# Imagens conceituais geradas por IA — seção "O que fazemos"

Esta pasta guarda as **imagens de inspiração / conceito** usadas nos cartões de
serviço da seção `#servicos` ("O que fazemos") do site.

> ⚠️ **Importante:** estas imagens são **referências conceituais geradas por
> inteligência artificial**, criadas apenas para ilustrar possibilidades de
> projeto. Elas **não representam trabalhos reais já executados** pela Queiroz
> Marcenaria e Carpintaria. Assim que houver fotos reais autorizadas, basta
> substituir os arquivos (mantendo os mesmos nomes) para que apareçam no site.

## Como funciona

O `index.html` já referencia os nomes de arquivo listados abaixo. Enquanto o
arquivo não existir, o site mostra automaticamente um **bloco de espaço
reservado** com o texto:

> "Imagem conceitual gerada por IA — substituir pelo arquivo final"

Quando você salvar a imagem com o nome exato indicado, ela passa a ser exibida
no lugar do espaço reservado — **sem precisar editar o HTML**.

## Onde salvar

Salve cada imagem **nesta mesma pasta**:

```
assets/images/inspiracoes/
```

## Recomendações técnicas

- **Formato:** `.jpg` (mantenha a extensão exata dos nomes acima).
- **Proporção:** paisagem, em torno de **3:2** (ex.: 1200 × 800 px).
- **Tamanho:** otimize para web (idealmente abaixo de ~300 KB cada).
- **Estilo:** rústico premium, madeira de verdade, luz quente e natural —
  coerente com a identidade visual do site (bege, marrom madeira, off-white).

## Como substituir por fotos reais no futuro

1. Gere/tire a foto real do trabalho.
2. Renomeie o arquivo com **exatamente** o nome esperado da tabela acima.
3. Salve aqui em `assets/images/inspiracoes/` (substituindo o arquivo anterior).
4. Pronto — a imagem aparece no cartão correspondente automaticamente.

Quando as imagens passarem a ser **fotos reais**, lembre-se de remover do
`index.html` a nota "imagens conceituais geradas por IA" da seção de serviços,
para refletir que passaram a ser trabalhos reais.
